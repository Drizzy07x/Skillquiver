How it works

A skill is a folder anchored by one instruction file.

The top of SKILL.md says what the skill does and when to use it. The host keeps that summary in mind and opens the rest only when the moment arrives. Some skills also include scripts, templates, or references that load only when needed.

Install

Choose your host.

The universal Plugins Directory is recommended for ChatGPT and Codex once the listing shows version 2.1.0. Claude Code can install the same 23-skill source catalog from the repository marketplace.

Plugins Directory recommended

Open the Plugins Directory in ChatGPT, search for Skillquiver, confirm that the listing shows version 2.1.0, and select Add.

Until 2.1.0 is approved, the public listing may still expose the smaller Skillquiver Core catalog. ChatGPT uses @ mentions for explicit skill selection. Repository installs are intended for local development and Claude Code.

Marketplace recommended

Run inside an interactive Claude Code session:

/plugin marketplace add Drizzy07x/Skillquiver
/plugin install skillquiver@skillquiver

Or run the equivalent commands from a terminal:

claude plugin marketplace add Drizzy07x/Skillquiver
claude plugin install skillquiver@skillquiver --scope user

Update with /plugin update skillquiver@skillquiver or claude plugin update skillquiver@skillquiver.

Manual

Copy the shared catalog for all 23 skills:

git clone https://github.com/Drizzy07x/Skillquiver.git
mkdir -p ~/.claude/skills
cp -r Skillquiver/skills/* ~/.claude/skills/

Use a project's .claude/skills/ folder instead for a project-only install.

Marketplace recommended

Run from a terminal:

codex plugin marketplace add Drizzy07x/Skillquiver
codex plugin add skillquiver@skillquiver

Refresh the marketplace and reinstall to update:

codex plugin marketplace upgrade skillquiver
codex plugin add skillquiver@skillquiver

Manual

Copy all 23 shared skills to the global agent directory:

git clone https://github.com/Drizzy07x/Skillquiver.git
mkdir -p ~/.codex/skills
cp -r Skillquiver/skills/* ~/.codex/skills/

Use a project's .agents/skills/ folder instead for a project-only install.

Planning5

  • brainstormingChatGPT + Claude Code + Codex Asks what you actually want before a line of code is written. you're starting something new and the details aren't settled.
  • writing-plansChatGPT + Claude Code + Codex Turns the idea into a written list of tasks, in order. you know what to build but nobody has written down the steps.
  • executing-plansChatGPT + Claude Code + Codex Works through a written plan one task at a time, stopping only if it gets stuck. a plan already exists and you want it carried out.
  • subagent-driven-developmentChatGPT + Claude Code + Codex Hands each task to its own helper agent and reviews the result before moving on. the tasks in the plan don't depend on each other.
  • dispatching-parallel-agentsChatGPT + Claude Code + Codex Sends out several helper agents at once, one per unrelated problem. you have two or more separate problems and no reason to fix them in order.

Execution7

  • test-driven-developmentChatGPT + Claude Code + Codex Writes the failing test first, then the smallest code that makes it pass. you're adding a feature or fixing a bug.
  • solve-efficientlyChatGPT + Claude Code + Codex Finds the few files that actually matter instead of reading the whole project. the change touches several parts of the codebase.
  • handle-host-boundariesChatGPT + Claude Code + Codex Handles a skill or tool that belongs to another agent host without pretending it exists. a request names a capability from another host.
  • execute-durablyChatGPT + Claude Code + Codex Keeps progress in a file on disk so long work can be picked up where it stopped. the job is long and might get interrupted.
  • refactor-safelyChatGPT + Claude Code + Codex Tidies code without changing what it does, with tests in place first. code is messy or duplicated but still has to work exactly the same.
  • using-git-worktreesChatGPT + Claude Code + Codex Sets up a separate working copy so your current work stays untouched. you're starting a feature and don't want to disturb what's already open.
  • communicate-clearlyChatGPT + Claude Code + Codex Keeps the answer as short as it can be without dropping the proof. you want less noise, or something explained in plain words.

Verification & debugging4

  • diagnose-systematicallyChatGPT + Claude Code + Codex Reproduces the failure, shrinks it, then tests one guess at a time. something breaks and nobody knows why yet.
  • verification-before-completionChatGPT + Claude Code + Codex Runs the command and reads the output before anyone says it works. you're about to hear “done”, “fixed”, or “all tests pass”.
  • verify-workChatGPT + Claude Code + Codex Checks finished work against real evidence and flags claims with nothing behind them. you want a second opinion on something that says it's complete.
  • research-systematicallyChatGPT + Claude Code + Codex Writes the question down first, then backs every answer with a source. comparing options, measuring, or checking how a library really behaves.

  • receiving-code-reviewChatGPT + Claude Code + Codex Checks each review comment against the code before changing anything. feedback arrives and some of it might be wrong.
  • finishing-a-development-branchChatGPT + Claude Code + Codex Runs the tests, asks how you want to land the work, then cleans up after it. the feature is finished and needs to go somewhere.

Working together

One feature, from idea to merge.

These aren't 23 separate tricks. Almost every step of building something has a portable skill that fits it. A normal run in ChatGPT, Claude Code, or Codex looks like this:

  1. 01 brainstorming Agree what you're building.
  2. 02 writing-plans Write the steps down, in order.
  3. 03 using-git-worktrees Get a clean workspace to build in.
  4. 04 subagent-driven-development Build it task by task, reviewed as you go.
  5. 05 test-driven-development Each task starts with a failing test.
  6. 06 verification-before-completion Run it. Read the output. Then say it works.
  7. 07 requesting-code-review Get the finished work reviewed.
  8. 08 finishing-a-development-branch Merge it, then clean up.
