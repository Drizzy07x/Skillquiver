Skillquiver

Effective August 12, 2026

Privacy Policy

Short version: Skillquiver is a package of instruction files and local helper scripts. The Skillquiver project does not operate a backend, create user accounts, or receive your prompts, source code, or personal data.

Publisher

Skillquiver is published and maintained under the public publisher name Drizzy07x. The source repository and support channel are hosted by the same GitHub account.

What Skillquiver collects

Skillquiver itself does not collect, transmit, sell, or retain personal information. The project website does not use Skillquiver-operated analytics, advertising trackers, account systems, or cookies.

Public plugin package

Skillquiver is a public package of 23 Agent Skills for ChatGPT and Codex. The same source catalog also supports Claude Code. It has the same local-only data behavior described in this policy and does not add a hosted backend, account, authentication system, MCP server, bundled hooks, or app UI.

Local files and commands

Some skills guide your agent to read or create files in your local workspace, run development commands, or preserve local evidence such as plans, logs, screenshots, backups, and test output. Those artifacts stay in locations shown or chosen during the workflow unless you direct an approved tool to send them elsewhere. Review proposed actions and host permission prompts before approving them.

Agent hosts and third-party tools

You use Skillquiver through an agent host such as ChatGPT, Claude Code, or Codex. A skill may also help you use a browser, source-control provider, package registry, or another tool that you have configured and approved. Those hosts and services may process data under their own terms and privacy policies. Skillquiver does not control their collection, retention, security, or deletion practices.

Marketplace and repository services

Downloading Skillquiver from GitHub, a host marketplace, or a public directory sends ordinary request information to that service. GitHub also processes information you choose to post in an issue. Do not include secrets or sensitive personal information in a public support issue.

Children's privacy

Skillquiver is a developer tool and is not directed to children. The project does not knowingly collect personal information from children.

Your choices and deletion

Because Skillquiver does not hold your data, there is no Skillquiver account or hosted record to delete. You can remove the plugin, delete locally created artifacts, and use each host or third-party provider's controls for data processed by that service.

Changes

This policy may be updated when Skillquiver's behavior or distribution changes. Material changes will be reflected here and in the repository history with a new effective date.

Contact

For privacy questions or support, open a GitHub issue.
